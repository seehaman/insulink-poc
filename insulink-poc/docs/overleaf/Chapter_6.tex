\section{Ethics and Data Protection}
HUPA-UCM is anonymised and published under a Creative Commons Attribution 4.0 licence; it is cited and is not redistributed in the project repository. Any data from real users is collected only with explicit written consent, stored encrypted, and deletable on request. The application is presented as educational support and never instructs a user to dose. A clinician will review safety thresholds before any pilot.
